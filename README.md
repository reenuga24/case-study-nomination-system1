# 🎓 Candidate Nomination System

A PHP-based web application that allows candidates to submit nominations and officers/admins to manage them.

---

## 📌 Overview
This system supports three user roles:

### 👤 Candidate
- Register and log in  
- Submit nomination with photo upload  
- View or delete own submissions  

### 🛡 Officer
- Log in  
- View all nominations  
- Edit or delete submissions  

### 👨‍💼 Admin
- Create officer accounts  
- Manage system users
